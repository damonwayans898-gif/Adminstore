🚀 COMO USAR A VERSÃO PREMIUM
═════════════════════════════════════════════════════════════════════════════════

1. SUBSTITUIR index.html

   Opção A (Manter ambas):
   ├─ index.html         (versão 1.0)
   └─ index_premium.html (versão 2.0)
   
   Depois mudar:
   • Apontar domínio para index_premium.html
   • Ou renomear index_premium.html → index.html

   Opção B (Substituir):
   └─ Copiar código de index_premium.html → index.html

2. ADICIONAR ARQUIVOS JAVASCRIPT

   Copiar para a mesma pasta:
   ├─ login.js      (autenticação)
   ├─ cadastro.js   (registro)
   └─ principal.js  (app manager)

3. ATUALIZAR REFERÊNCIAS

   No HTML:
   ```html
   <script src="/principal.js"></script>
   <script src="/login.js"></script>
   <script src="/cadastro.js"></script>
   ```

4. CONFIGURAR SUPABASE

   Editar em todos os arquivos:
   ```javascript
   const SUPABASE_URL = 'https://seu-projeto.supabase.co';
   const SUPABASE_KEY = 'sua-chave-publica';
   ```

5. INTEGRAR EMAILS

   Usar templates de email-templates.html
   • Copiar HTML dos templates
   • Configurar variáveis {{CODE}}, {{USER_NAME}}, etc
   • Usar em Sendgrid/Mailgun/Supabase Mail

6. TESTAR

   ```bash
   python -m http.server 8000
   # Ou: npx http-server
   # Abrir: http://localhost:8000
   ```
